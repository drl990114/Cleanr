# Cleanr 概览

Cleanr 是一款 AI 友好的跨平台磁盘清理工具，覆盖**应用与浏览器缓存、日志、临时文件、下载
文件和开发产物**。它运行在终端中，解释每个条目为什么被匹配，并由你决定哪些内容
进入系统回收站。结构化只读分析为 AI Agent 提供候选大小、匹配原因、置信度和风险说明，
便于它协助审阅和准备计划，最终清理决定仍由你做出。

安全检查贯穿这个流程：分析只读，默认在清理前确认，每项移动前重新核验所选目标；
Agent 执行还会将已审阅计划与重新扫描的结果核对。清理使用系统回收站，并保留本地
记录以支持尽力恢复。

常见候选项包括：

- 来自已知用户级清理位置的浏览器和应用缓存；
- 日志、诊断报告和临时文件；
- 移除前需要你判断用途的下载文件与安装包；
- `node_modules` 等项目依赖；
- Rust `target`、Xcode `DerivedData` 等构建产物；
- Cargo、npm、pnpm、pip、Gradle 等工具的包缓存。

可以选择目录，或按类别扫描已知清理位置。覆盖范围取决于平台和所选范围，详见
[扫描方式](./using-cleanr.md)。

## 基本流程

Cleanr 将“发现”与“删除”明确分开：

1. **扫描**一个或多个目录。
2. **审阅**匹配到的候选项和风险说明。
3. **选择**真正想移除的条目。
4. **确认**清理。
5. 必要时**恢复**历史清理运行。

文件不会仅仅因为被发现就自动清理。高置信度、可重建的内容可能会被预选，
但执行前仍然可以修改计划。

## 安全机制概览

- 清理会把条目移动到系统回收站，不会永久删除。
- 计算候选与已选字节总量前会消除父子目录重叠；移入回收站通常不会立即增加可用空间。
- 执行前会再次检查目标；发生变化的文件、符号链接、扫描根目录外的路径和
  Cleanr 受保护数据都会被拒绝。
- 每次清理和恢复都会写入本地清单，便于检查结果。
- 插件默认是声明式数据文件；动态 hook 需要显式信任。

具体保证和恢复限制见[安全与恢复](./safety-and-recovery.md)。

## Cleanr 适合你吗？

如果你希望通过键盘界面审阅磁盘清理，无论是应用缓存、旧下载文件还是项目构建产物，
都可以使用 Cleanr。它不是通用系统加速器、注册表清理工具，也不是无人值守的自动删除服务。
