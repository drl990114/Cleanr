Cleanr · 开源 · 终端优先

AI 友好的磁盘清理，安全优先。

为你的 AI Agent 提供应用与浏览器缓存、日志、临时文件、下载文件和开发产物的结构化只读分析。看清原因与风险，再决定哪些内容移入系统回收站。

配合 AI Agent 使用直接体验终端
npm install --global cleanr-cli

macOS · Linux · Windows · 平台支持与限制

01

为 AI Agent 提供依据

结构化只读扫描结果包含大小、匹配原因、置信度与风险说明，便于 Agent 理解和审阅。

02

审阅后，再清理

看清原因与风险，再选择清理内容。默认在清理前确认；Agent 执行需要你对确切计划的授权。

03

每次移动前都复核

复核所选路径和文件状态，拒绝受保护路径与符号链接目标。条目移入系统回收站，并保留本地记录以支持尽力恢复。

看看第一次扫描​

扫描一个项目，查看候选项，然后退出，全程不改变文件。

安全与恢复

确认的内容会移入系统回收站。在你自行清空回收站前，空间不一定释放；清空后，Cleanr 无法再恢复这些内容。 恢复限制

Cleanr 不会上传分析报告。使用云端 AI Agent 时，Agent 可能将工具输出发送给服务商。共享报告前，请先决定允许它读取哪些信息。 Agent 数据边界
