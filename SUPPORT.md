# Support and feedback

Start with [Quick start](https://drl990114.github.io/Cleanr/docs/quick-start) or
[Troubleshooting](https://drl990114.github.io/Cleanr/docs/troubleshooting).
Check `cleanr --version`; documentation marked Unreleased may describe newer
source than your installed package.

- [Installation or terminal problem](https://github.com/drl990114/Cleanr/issues/new?template=installation.yml)
- [Unexpected candidate or missing rule](https://github.com/drl990114/Cleanr/issues/new?template=rule-match.yml)
- [Cleanup or restore failure](https://github.com/drl990114/Cleanr/issues/new?template=recovery.yml)
- [Questions and ideas](https://github.com/drl990114/Cleanr/discussions)
- [Private security report](https://github.com/drl990114/Cleanr/security/advisories/new)

Reports are voluntary. Include the version, OS/CPU, terminal, installation method,
and shortest command or key sequence that reproduces the problem. Use generated
example paths, and share only a redacted error excerpt. Do not attach original
analysis JSON, saved plans, manifests, home-directory listings, or credentials.
No automatic report upload is needed.

For a restore failure, preserve the original Trash item and Cleanr state. Do not
empty Trash or repeatedly retry a changed target. State whether the original
path now exists and whether the item is still in Trash, without exposing either
path. Support has no established response-time guarantee.

## 简体中文

先查看[快速开始](https://drl990114.github.io/Cleanr/zh-Hans/docs/quick-start)或
[故障排查](https://drl990114.github.io/Cleanr/zh-Hans/docs/troubleshooting)，并用
`cleanr --version` 确认版本。文档中的“未发布”能力可能尚未进入已安装版本。

上述表单支持中英文反馈：安装或终端问题、规则误匹配/漏匹配、清理或恢复失败分别提交；
一般问题用讨论区，安全问题用私密漏洞报告。请附版本、系统/CPU、终端、安装方式和
最短复现步骤；路径使用生成示例，只分享脱敏错误片段。不要上传原始分析 JSON、计划、
清单、主目录列表或凭证，不需要自动上传报告。

恢复失败时保留原回收站条目和 Cleanr 状态，不清空回收站，也不要对已变化的目标反复
重试。说明原路径是否已存在、条目是否仍在回收站即可，无需披露路径。目前没有响应
时限承诺。
